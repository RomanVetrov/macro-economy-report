cli.py - только argparse, проверка аргументов, собрать пайплайн

loader.py - читать CSV - отдавать записи

reports/average_gdp.py - логика отчёта (посчитать среднее и отсортировать)

reports/registry.py - выбрать отчёт по имени --report

render.py - вывести таблицу через tabulate

reports/base.py - ощий интерфейс отчёта, чтобы добавлять новые без переписывания CLI



Использую абстрактные интерфейсы, аля универсальность- Iterable и Mapping вместо конкретных list и dict. Это делает код гибким: функция сможет работать с любыми источниками данных (от списков до ленивых генераторов из БД), не требуя лишних преобразований типов в памяти
